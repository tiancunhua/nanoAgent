多步任务复用同一个 messages

真正的关键不是 `for step in steps`，而是步骤之间共用上下文。

 161     messages.append({"role": "user", "content": task})
 162     actions = []
 163     for _ in range(max_iterations):
 164         response = client.chat.completions.create(
 165             model=os.environ.get("OPENAI_MODEL", "gpt-4o-mini"),
 166             messages=messages,
 167             tools=tools,
 168         )
 169         message = response.choices[0].message
 170         messages.append(message)
 171         if not message.tool_calls:
 172             return message.content, actions, messages
 173         for tool_call in message.tool_calls:
 174             function_payload = getattr(tool_call, "function", None)
 175             if function_payload is None:
 176                 continue
 177             function_name = str(getattr(function_payload, "name", ""))

 199 def run_agent_plus(task, use_plan=False):
 200     memory = load_memory()
 201     system_prompt = (
 202         "You are a helpful assistant that can interact with the system. Be concise."
 203     )
 204     if memory:
 205         system_prompt += f"\n\nPrevious context:\n{memory}"
 206     messages = [{"role": "system", "content": system_prompt}]
 207     if use_plan:
 208         steps = create_plan(task)
 209     else:
 210         steps = [task]
 211     all_results = []
 212     for i, step in enumerate(steps, 1):
 213         if len(steps) > 1:
 214             print(f"\n[Step {i}/{len(steps)}] {step}")
 215         result, actions, messages = run_agent_step(step, messages)
 216         all_results.append(result)
 217         print(f"\n{result}")
 218     final_result = "\n".join(all_results)
 219     save_memory(task, final_result)

Talk Track

讲课只讲这 3 件事

  • 规划不是额外魔法，只是把任务拆解前置了一次。
  • 跨步骤共享 `messages`，就是让 Agent 在执行链路里“不断记住自己刚做了什么”。
  • 长期记忆最开始不用上复杂系统，先把写入和回放跑通。

Pitfalls

容易踩坑

  • 记忆窗口过大，后面会迅速碰到上下文爆炸。
  • 规划失败时一定要有降级路径，不能卡死。
  • 把所有历史都塞回 prompt，不等于真正的记忆系统。
