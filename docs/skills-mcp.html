本讲聚焦三层能力扩展：一个最小 Rule、一个最小 Skill、一个最小 MCP 工具。重点不在配置多复杂，而在它们分别注入到上下文还是工具列表。

Scenario

什么时候会用到

团队有自己的代码规范、有内部 API、还希望不同项目用不同能力，但又不愿意把这些都硬写进脚本里。能力外置，就是把这些差异从代码里抽到项目目录中。

 208 def load_rules():
 209     rules = []
 210     if not os.path.exists(RULES_DIR):
 211         return ""
 212     try:
 213         for rule_file in sorted(Path(RULES_DIR).glob("*.md")):

 227 def load_skills():
 228     skills = []
 229     if not os.path.exists(SKILLS_DIR):
 230         return []
 231     try:
 232         # 这里先只扫描 Skill 文件，不急着把完整内容都交给大模型。

 235             Path(SKILLS_DIR).glob("*.md")

 239         return skills

 244 def parse_markdown_skill(path):
 245     content = path.read_text(encoding="utf-8")
 246     metadata = {}
 247     body = content
 248     # frontmatter 是给模型判断用的轻量信息；body 是后续可展开的完整 Skill。
 249     if content.startswith("---\n"):
 250         end = content.find("\n---", 4)
 251         if end != -1:
 252             frontmatter = content[4:end].strip()
 253             body = content[end + 4 :].strip()
 254             for line in frontmatter.splitlines():
 255                 if ":" not in line:
 256                     continue
 257                 key, value = line.split(":", 1)
 258                 metadata[key.strip()] = value.strip()
 259     name = metadata.get(
 260         "name", path.parent.name if path.name == "SKILL.md" else path.stem
 261     )
 262     triggers = [
 263         trigger.strip().lower()
 264         for trigger in metadata.get("triggers", "").split(",")
 265         if trigger.strip()
 266     ]
 267     return {
 268         "name": name,
 269         "description": metadata.get("description", ""),
 270         "when_to_use": metadata.get("when_to_use", ""),
 271         "triggers": triggers,
 272         "path": str(path),
 273         "content": body,
 274     }

 277 def format_skill_summary_for_prompt(skill):
 278     # 第一阶段：只把 Skill Registry 放进 prompt。
 279     # 大模型先看到有哪些 Skill、何时使用、详情文件在哪里，但还看不到完整手册。
 280     lines = [f"- {skill['name']}: {skill.get('description', '')}"]
 281     when_to_use = skill.get("when_to_use")
 282     if when_to_use:
 283         lines.append(f"  When to use: {when_to_use}")
 284     if skill.get("triggers"):
 285         lines.append(f"  Triggers: {', '.join(skill['triggers'])}")
 286     lines.append(f"  Detail file: {skill['path']}")
 287     return "\n".join(lines)

 290 def parse_selected_skill_names(raw_content, known_names):
 291     text = (raw_content or "").strip()
 292     parsed = []
 293     try:
 294         parsed = json.loads(text)
 295     except json.JSONDecodeError:
 296         start = text.find("[")
 297         end = text.rfind("]")
 298         if start != -1 and end > start:
 299             try:
 300                 parsed = json.loads(text[start : end + 1])
 301             except json.JSONDecodeError:
 302                 parsed = []
 303     if isinstance(parsed, dict):
 304         parsed = parsed.get("skills", []) or parsed.get("selected_skills", [])
 305     if not isinstance(parsed, list):
 306         parsed = []
 307
 308     known_lookup = {name.lower(): name for name in known_names}
 309     selected = []
 310     for item in parsed:
 311         skill_name = known_lookup.get(str(item).strip().lower())
 312         if skill_name and skill_name not in selected:
 313             selected.append(skill_name)
 314     if not selected:
 315         # 有些模型会输出一句解释而不是纯 JSON。这里仍然只解析模型输出，
 316         # 不根据用户任务做 Python 侧匹配。
 317         lowered_text = text.lower()
 318         for name in known_names:
 319             if name.lower() in lowered_text:
 320                 selected.append(name)
 321     return selected

 324 def select_skills_with_model(task, skills):
 325     if not skills:
 326         return []
 327     registry = "\n".join(format_skill_summary_for_prompt(skill) for skill in skills)
 328     # 这里不是 Python 代码替模型做选择，而是发起一次轻量模型决策：
 329     # 模型只看到 Skill Registry 和用户任务，然后返回本轮要展开的 Skill 名称。
 330     response = client.chat.completions.create(
 331         model=os.environ.get("OPENAI_MODEL", "gpt-4o-mini"),
 332         messages=[
 333             {
 334                 "role": "system",
 335                 "content": (
 336                     "You decide which skills should be progressively loaded. "
 337                     "If the task explicitly names a skill, include that skill. "
 338                     "Only output a JSON array of skill names. Output [] if no skill "
 339                     "is needed."
 340                 ),
 341             },
 342             {
 343                 "role": "user",
 344                 "content": f"# Skill Registry\n{registry}\n\n# User Task\n{task}",
 345             },
 346         ],
 347     )
 348     raw_selection = response.choices[0].message.content
 349     selected_names = parse_selected_skill_names(
 350         raw_selection, [skill["name"] for skill in skills]
 351     )
 352     return [skill for skill in skills if skill["name"] in selected_names]

 414 def run_agent_with_external_capabilities(task):
 415     rule_count = count_rule_files()
 416     rules = load_rules()
 417     skills = load_skills()
 418     mcp_tools = load_mcp_tools()
 419     all_tools = base_tools + mcp_tools
 420     context_parts = [
 421         "You are a helpful assistant that can interact with the system. Be concise."
 422     ]
 423     if rules:
 424         context_parts.append(f"\n# Rules\n{rules}")
 425         print(f"[Rules] Loaded {rule_count} rule files")
 426     if skills:
 427         # 先注册 Skill 摘要，相当于给模型一张能力目录。
 428         context_parts.append(
 429             f"\n# Skill Registry\n"
 430             + "\n".join(format_skill_summary_for_prompt(skill) for skill in skills)
 431         )
 432         skill_names = [skill["name"] for skill in skills]
 433         print(
 434             f"[Skills] Registered {len(skills)} skill summaries: "
 435             f"{', '.join(skill_names)}"
 436         )
 437     selected_skills = select_skills_with_model(task, skills)
 438     if selected_skills:
 439         # 再按模型对本轮任务的选择结果，追加完整 Skill 详情。
 440         context_parts.append(
 441             f"\n# Loaded Skill Details\n"
 442             + "\n\n".join(
 443                 format_skill_detail_for_prompt(skill) for skill in selected_skills
 444             )
 445         )
 446         skill_names = [skill["name"] for skill in selected_skills]
 447         print(
 448             f"[Skills] Model selected {len(selected_skills)} skill details: "
 449             f"{', '.join(skill_names)}"
 450         )
 451     if mcp_tools:
 452         tool_names = [tool["function"]["name"] for tool in mcp_tools]
 453         print(f"[MCP] Loaded {len(mcp_tools)} MCP tools: {', '.join(tool_names)}")

name: todo_prioritizer
description: 给候选修复项排序：安全风险第一，阻塞运行第二，核心功能第三，文档或示例最后；如果只允许输出 3 项，舍弃文档或示例项，并保持输出简洁。
when_to_use: 当任务要求整理修复顺序、挑选优先级或从多个候选问题中选出下一步行动时使用。
triggers: todo_prioritizer, 修复顺序, 优先级, 候选修复项, 最该先修
---

# Todo Prioritizer

## Use When

当任务要求整理修复顺序、挑选优先级，或从多个候选问题中选出下一步行动时使用。

## Priority Order

1. 安全风险
2. 阻塞运行
3. 核心功能
4. 文档或示例

## Steps

1. 先识别每个候选项属于安全风险、阻塞运行、核心功能、文档示例中的哪一类。
2. 按安全风险、阻塞运行、核心功能、文档示例的顺序排序。
3. 如果题目要求最多 3 项，只输出前三项。
4. 每项用“优先级 - 类别 - 事项”的短格式。
5. 最后用一句话说明被舍弃项为什么靠后。

## Output Example

```text
1. 优先级 - 安全风险 - 删除用户接口缺少权限校验
2. 优先级 - 阻塞运行 - 应用启动时报错无法运行
3. 优先级 - 核心功能 - 搜索结果分页偶尔重复

舍弃项：README 示例命令有错别字（文档或示例类，优先级最低）。
```

Takeaway

这一讲会看懂什么

  • 知道 Skill 负责补充知识，Rule 负责约束行为，MCP 负责接入外部工具。
  • 能识别 Rules、Skills、MCP 各自的加载来源，以及它们如何拼装进上下文与工具列表。
  • 理解工程化 Agent 的关键不在于继续堆内置逻辑，而在于能力与约束的外置。

Key Points

三个核心要点

  • 最小 Rule 用来约束输出行为，最小 Skill 用来补充任务知识，最小 MCP 用来扩展可调用工具。
  • Rules、Skill Registry 与模型选择后的 Skill 详情进入 prompt，MCP 最终进入 tools，注入位置不同，作用也不同。
  • DEFAULT_MAX_ITERATIONS = 10 是演示友好值，能避免复杂搜索在结论前过早中断。

Pitfalls

容易误解

  • 将全部约束堆入 Rule，会模糊职责边界，模型也更难稳定执行。
  • Skills 过多会稀释上下文，MCP 工具过多会降低模型的工具选择准确率。
  • 迭代次数调高会改善演示完整度，但也会增加 token 成本与执行时间。
  • 规则、技能、工具描述互相冲突时，模型表现会显著不稳定。
